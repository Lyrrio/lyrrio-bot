# Sources du catalogue

Les noms sont des données factuelles extraites des pages publiques de personnages
MyAnimeList par `update_catalog.py`. En cas d’indisponibilité, le script utilise le
jeu de données `fadhilakbar/anime-characters-dataset` publié sous licence CC BY 4.0 :
https://huggingface.co/datasets/fadhilakbar/anime-characters-dataset

Jikan a servi de référence d’API pendant la conception :
https://docs.api.jikan.moe/
